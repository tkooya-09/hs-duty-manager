# ⭐ 화성 별별 비상근무 관리 플랫폼 ⭐

산불조심기간 비상근무 편성·수당 산정을 보조하는 **참고용 업무 보조 도구**입니다.

🌐 **바로 사용하기**: https://tkooya-09.github.io/hs-duty-manager/

> ⚠️ 첫 로딩은 약 2~3초 걸립니다 (엑셀 라이브러리 내장 1MB)

---

## 📋 주요 기능

| 기능 | 설명 |
|---|---|
| 🗓 자동 편성 | 평일조·주말조 분리, 8조 구성 자동 편성 |
| ⭐ 4단계 위기경보 | 관심·주의·경계·심각 단계별 인원 조정 |
| 💰 수당·대체휴무 | 개인별로 수당↔대체휴무 자유 선택 |
| 🔄 인사 발령 대응 | 명단 교체 시 기존 편성 자동 갱신 |
| 📊 엑셀 출력 | 편성표·개인별·월별 통합 엑셀 추출 |
| 💾 자동 저장 | 담당자 PC localStorage 자동 보관 |

## 🔒 보안 정책 (공공기관 내부 전용)

### 처리하지 않는 정보
- ❌ 주민등록번호
- ❌ 계좌번호
- ❌ 연락처·주소
- ❌ 건강·민감정보

### 처리하는 정보 (공무원 조직도 수준)
- ✅ 성명, 직급
- ✅ 성별, 운전면허 보유 여부
- ✅ 소속 부서

### 외부 통신 차단
- **외부 서버·API·CDN·웹폰트 호출 0건**
- Content Security Policy 적용: `connect-src 'none'`
- 엑셀 라이브러리(SheetJS) HTML 직접 내장
- 오프라인·내부망에서도 완전 동작

### 데이터 저장
- 담당자 PC의 브라우저 localStorage에만 보관
- 외부 서버·클라우드·DB 미사용
- 헤더 [🗑 일괄 삭제] 또는 [🧹 저장 삭제] 1클릭으로 완전 삭제

### 입력값 보호
- XSS 차단 (HTML 자동 이스케이프)
- 다운로드·인쇄 시 성명 마스킹 옵션 (홍○동)
- 인쇄 워터마크: "내부 전용 · 외부유출금지"

## 🚨 사용 시 주의사항

1. **본 사이트(GitHub Pages)는 데모·열람용**입니다.
2. **실제 직원 명단 입력은 권장하지 않습니다.**
3. 실제 업무 시: HTML 파일을 다운로드하여 **본인 PC에서 직접 실행**
4. 본인 PC에서 입력한 데이터는 **다른 사용자에게 노출되지 않습니다** (localStorage)

---

## 💡 활용 가이드

### 실제 업무용 사용법 (권장)
1. 우측 상단 [Code] → [Download ZIP] 클릭
2. 압축 풀고 `index.html` 더블클릭
3. 본인 PC에서만 명단 입력·관리

### 데모·교육용 사용법
1. 위 GitHub Pages URL 접속
2. 가상 명단(홍길동·성춘향 등)으로 기능 체험
3. 새로고침해도 본인 PC localStorage에만 임시 저장됨
